# 本机演示材料

在宿主机执行 `bash scripts/presentation_local.sh`，从同一份内容生成可编辑 PPT、矢量 PDF、Word 讲稿和本机材料 ZIP。统计、训练和 Notebook 执行仍在 Docker 内完成。

课堂内容先介绍论文的研究问题、方法和结论，再介绍本组复现实验、结果与改进。与研究无关的文件管理、排错和交付过程不进入 PPT 或讲稿。

图像数据统一称为“从 Kaggle 下载的压缩数据集”，说明原始图像包约 122GB，以及实际采用的分辨率、划分和采样规模。结果强调实验支持论文的主要定性描述，具体分数与降幅使用实际记录，不将差异统一描述为轻微误差。

封面后第2页为目录，保持21页主讲25分钟，以及两个讨论问题。每个问题和答案分别占一页，后4页共5分钟。

`canvas.py` 在本机生成 PPT 与 PDF；`presentation/speech_content.json` 是逐页讲稿，动态数值来自容器导出的结果。PDF 的 CJK 字体子集必须保留字形ID，避免字符映射错误。`presentation/check_slides.py` 校对页数、时长、备注、PDF文字与实际页面预览。

本目录整体不纳入教师实验交付包或镜像。

## Notebook组织与展示

主目录保留01（指标复现）、02（真实人脸表情识别模型训练验证）、03（不足与改进）。课堂在VS Code已有容器连接中浏览代码、注释与已完成输出，不现场执行实验。

本目录只放上台使用的 PPT、PDF、讲稿、制作代码与本机 `.venv/`。实验过程与结果集中展示在Notebook，来源说明与程序必需的验证数据位于 `results/`。

字体：PPT明确指定微软雅黑（Microsoft YaHei）及zh-CN东亚文字属性；PDF与图表使用Noto Sans CJK SC简体黑体。读取TTC必须采用fontconfig返回的字体索引，不能固定为0（日文字形）。PDF嵌入简体字形，保持跨机器显示一致。

章节统一为：论文内容、复现工作、不足与改进、代码演示、讨论。第20页属于代码演示，结果仍归入复现工作。

第5页包含ENS、SEI、V、Z定义；第13页包含分组召回率与宏平均；第18页包含截断、类内归一和加权损失。公式在本机使用Matplotlib数学排版生成；检查脚本检查文字与公式、图表的交叠。
